# Educational Blockchain in Go ⛓️

Простой учебный блокчейн, написанный на **Golang** с нуля. Проект создан для глубокого погружения в архитектуру распределённых систем, работы алгоритмов консенсуса и практического изучения внутренних механизмов Go.

---

## 🚀 Реализованный функционал

- **Структура блоков:** Хранение данных (payload), хэша текущего блока, хэша предыдущего блока (`PrevBlockHash`), метки времени (`Timestamp`) и счетчика `Nonce`.
- **Хэширование:** Использование криптографической функции **SHA-256** для создания уникальных идентификаторов блоков и обеспечения неизменяемости цепочки.
- **Proof-of-Work (PoW):** Механизм майнинга с подбором `Nonce` для удовлетворения требуемой сложности (сложность регулируется количеством целевых нулей в хэше).
- **Проверка целостности:** Алгоритм валидации цепи, проверяющий корректность связей между блоками и соответствие Proof-of-Work.

---

## 🛠️ Технологии

- **Язык:** Go 1.2x+
- **Стандартная библиотека:** `crypto/sha256`, `bytes`, `encoding/binary`, `time`, `strconv`
